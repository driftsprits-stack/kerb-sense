# Kerb Sense v2 assets

Made by the local design agent for the minimal redesign. Use these files; do not edit them in the code branch.

| File | Use |
|---|---|
| `booth-hero.svg` | Hero booth, three-quarter angle, white body (place on black) |
| `booth-assembled.svg`, `booth-exploded.svg` | Assembled / exploded switch. Same frame, so the switch does not jump. Markers 1 to 6 match `parts/` |
| `parts/01-screen-glass.svg` to `06-hooks.svg` | Parts grid. `03-movement-buttons.svg` is the four buttons as one part |
| `booth-dimensions.svg` | Dimension drawing, 70 x 65 x 75 cm |
| `charts/fatalities.svg` | Problem section chart (SPF Annual Road Traffic Situation 2025) |
| `charts/budget.svg` | Budget section chart |
| `steps/step-1-wait.svg` to `step-6-phone.svg` | Crossing stepper: wait, look right, look left, look right again, cross, phone after |
| `renders/*.svg` | Flat renders at 70 x 65 x 75 cm (viewer fallbacks) |
| `booth-flat.glb` | 3D model scaled to 70 x 65 x 75 cm. Replaces `public/models/booth-flat.glb` (compress it as before) |

Colours: black, white, paper and green only. All flat, no gradients or opacity.
