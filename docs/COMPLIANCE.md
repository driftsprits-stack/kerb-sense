## Section 6. Owner-only actions

1. Install the Claude GitHub App with write access. **Done** (pushes succeed).
2. Settings → Pages → Source: **GitHub Actions**. Then **Enforce HTTPS**.
3. Settings → Code security: turn on **secret scanning**, **push protection** and **Dependabot alerts**.
4. Settings → Branches: protect `main` (require a pull request, require the CI status checks).
5. Google Search Console: add the property `https://driftsprits-stack.github.io/kerb-sense/`, verify with the HTML tag method, and give the team the `<meta name="google-site-verification">` tag to add to `index.html`. Then submit `https://driftsprits-stack.github.io/kerb-sense/sitemap.xml`.
6. Give a public contact email for the team, or confirm there is none (item 18).
