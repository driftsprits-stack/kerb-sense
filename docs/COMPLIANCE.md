# Compliance matrix

Every numbered item from `website-handoff/WEBSITE-STANDARDS.md`, with one status:

- **DONE**: the file, test or screenshot that proves it.
- **N/A**: the reason.
- **OWNER**: the repository owner must do it. The exact steps are listed.
- **BLOCKED**: content or a decision is missing. Nothing was invented.

Last updated: 3 October 2026, for the owner's review (minimal page, sticky booth tour, part detail, number dial, one red for "not allowed").
